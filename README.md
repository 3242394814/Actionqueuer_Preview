# 黑化排队论 · 动作预览

这是为萌萌的新发布的[黑化排队论](https://steamcommunity.com/sharedfiles/filedetails/?id=3136701076)制作的补丁Mod
你可以在[Steam创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3514363098)中找到这个模组

## 如何使用？
在Steam创意工坊中同时订阅[黑化排队论](https://steamcommunity.com/sharedfiles/filedetails/?id=3136701076)和[黑化排队论 · 动作预览](https://steamcommunity.com/sharedfiles/filedetails/?id=3514363098)
接着在[饥荒联机版](https://store.steampowered.com/app/322330) -> 模组 -> 本地模组中同时开启黑化排队论和黑化排队论 · 动作预览，接着进入游戏即可
